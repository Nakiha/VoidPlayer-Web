# 桌面安装与离线使用

本页适用于本地运行包或自托管的完整版。公开的 Sites 静态版不提供 PWA 安装入口；可直接在线打开本地文件，见 [Sites 说明](sites.md)。

## 安装

在本机打开正式构建的播放器首页，或通过受信任的 HTTPS 访问远程部署。Chrome / Edge 可从地址栏或浏览器菜单安装 VoidPlayer；Safari 可将页面添加到程序坞或主屏幕。开发页面使用实时资源。

「设置 → 关于 → Web 应用」提供安装入口：

- Chrome / Edge 支持时弹出原生安装窗口。
- Mac Safari 使用「文件 → 添加到程序坞」，完成后可在个人「应用程序」文件夹找到 VoidPlayer。首次访问会提示一次；应用内的安装按钮提供操作指引。
- iPhone / iPad Safari 使用「分享 → 添加到主屏幕」。

安装后的独立窗口显示「已安装」。卸载 Mac Safari Web 应用时，可在个人「应用程序」文件夹将其移到废纸篓。

## 离线资源与更新

安装后首次联网打开会在后台准备播放器、语言包及解码器。资源准备好后可离线打开本地视频；媒体库、分享与服务器工作区仍需连接原服务。清除浏览器站点数据后，需要再次联网准备。

升级期间可以继续当前评审。关闭所有旧播放器窗口后，已准备好的新版本会接替旧版。正式前端发布、旧窗口保留及回退步骤见[更新说明](operations.md#只发布前端)。

工作区不包含原视频。持久文件访问依赖浏览器接口和用户授权，不能把离线资源已准备好理解为已永久取得视频读取权限；重要评审请导出工作区备份。

## 从系统打开文件

安装到桌面的 Chrome / Edge 后，可在系统「打开方式」中选择 VoidPlayer 打开 `.voidplayer` 工作区或本地视频。默认打开方式由用户在系统中选择。

一次选择多个视频会在新窗口按顺序占用空轨道；同时选择一个工作区和原视频可以还原本地片源。文件由浏览器在本地读取。

通用的 `.json`、`.gz` 和可能是源码的 `.ts` 保留拖放及应用内打开。Safari 等未提供系统文件交付接口的浏览器也可使用这些入口。
