# Roadmap

2026-09-07 确定。实施顺序：**3 部署基础 → 1 媒体库 → 2 管理后台**，随后完成首个正式 release 的验收。本文记录计划，未勾选项尚未完成。

## 已确定的交付方向

- 用 Bun `build --compile` 将服务端及运行时打成独立可执行文件，最终用户无需安装 Node、Bun 或 npm 依赖。
- 发布包包含 `voidplayer` 可执行文件（Windows 为 `.exe`）、构建后的网页/WASM 资源、配置示例和许可证。首版保留资源目录，不要求所有资源塞进单个二进制。
- 配置、索引数据库、日志及后续上传内容放在独立可写数据目录；程序升级不覆盖用户数据。
- 本地与远端运行同一套服务。开发、前端构建和现有测试可以继续使用 Node/npm，发布运行时采用 Bun。
- 为支持的操作系统和架构分别构建、验证产物；具体首发平台矩阵在部署阶段确定，不把交叉编译成功当作目标平台验收通过。

## 阶段 3：可部署预览版

目标：脱离开发仓库，在实际服务器或本地机器上解压并启动，先发布 prerelease。

- [x] 验证 Bun 下的 HTTP/HEAD/Range、流式读取与中断、文件系统、进程信号及正常退出；保留现有会话和解码架构。当前已在 macOS ARM64 独立产物通过。
- [x] 固定 Bun 1.4.2 并生成服务端可执行文件，明确程序目录、资源目录、配置路径和数据目录，支持从任意工作目录启动。
- [x] 完成首次配置、目录权限和启动错误提示，以及健康/就绪检查。
- [ ] 验证本地访问、远端认证入口、HTTPS、视频所需响应头和媒体读取。
- [ ] 打包网页与两种 WASM core，携带本项目和依赖许可证、源码与构建来源说明。
- [ ] 生成可追溯的版本信息、产物清单和校验和，建立自动构建与产物测试流程。
- [ ] 明确启动、停止、后台运行、升级、备份和恢复方式；验证升级保留配置及数据。
- [ ] 在没有 Node/Bun、没有源码与 node_modules 的干净环境验收，并部署到真实媒体存储环境。

本阶段先使用现有媒体库能力验证部署。只预留管理入口，不提前铺开完整 admin 页面。

## 阶段 1：媒体库重做

目标：可靠管理多个物理或网络存储根目录下的大量嵌套视频文件，播放不受全库扫描阻塞。

- [ ] 明确稳定的根目录/媒体 ID、内容版本、目录层级及旧工作区引用的兼容或迁移方式。
- [ ] 使用持久化索引，数据库存放在服务端本地数据目录；重启后可查询上次结果。
- [ ] 后台扫描与媒体读取分离，提供扫描进度、错误、取消与恢复能力。
- [ ] 目录浏览、面包屑、分页和当前目录/全库搜索，替代一次返回并渲染整个媒体库。
- [ ] 处理深层目录、大量文件、文件写入中/替换/删除和权限不足，不再静默漏项。
- [ ] 网络存储首版使用操作系统已挂载的路径；离线时保留索引并标记状态，重连后校准。
- [ ] 增量更新、手动刷新与周期校准配合，文件监听仅作提示，不作为网络存储完整性的唯一依据。
- [ ] 验证扫描期间多轨 Range 请求、断线恢复、服务重启及现有工作区导入。

详细候选模型见 [媒体库演进方案](media-library-evolution.md)。收藏、服务器评审集合等扩展能力不自动成为本阶段必做项。

## 阶段 2：服务端管理后台

目标：围绕实际的数据和任务提供管理能力，与播放器共用服务端接口。

- [ ] 独立 `/admin` 入口；播放器连接状态入口在新标签页打开服务端管理界面。
- [ ] 管理身份、访问权限和写操作边界。
- [ ] 管理媒体根目录与扫描任务，查看不可读目录、离线存储和索引状态。
- [ ] 展示服务版本、运行状态、连接、资源使用及诊断日志。
- [ ] 分别测量客户端到服务端吞吐、存储读取能力和并发服务能力，明确测试条件与耗时；主动测速由用户触发。
- [ ] 定义端侧上传/编辑对象的持久化、归属、版本与冲突处理，再提供对应的检视和管理页面。

上传/编辑内容的具体范围待该阶段明确，不预先承诺通用文件管理器或完整协作平台。客户端诊断日志仍只在用户主动上传时发送。

## 首个正式 release 验收

- [ ] 用真实嵌套目录与网络存储完成端到端评审。
- [ ] 在声明支持的平台验证安装、首次启动、重启、升级、数据迁移与备份恢复。
- [ ] 验证资源齐全、许可证齐全、远端访问边界及升级失败后的恢复路径。
- [ ] 从发布产物运行回归，而不只测试源码启动；发布已知限制和操作文档。

## 当前状态

阶段 3 已开始，发布脚本已改为独立可执行文件加资源目录。macOS ARM64 预览产物通过空 PATH、与源码无关的工作目录、归档校验、初始化、并发 Range、中断、网关身份和更换程序目录保留配置/日志测试；独立服务上的四组 WebKit 播放基准通过。

已加入三平台原生构建/产物测试工作流，尚未在远端运行。Linux/Windows 原生运行、Docker/HTTPS 集成、签名与公证、真实网络存储部署及 core 产物精确构建来源仍待验收，因此不标记阶段 3 完成，也未发布公开 release。应用和 Bun 的源码/许可说明已随包提供；core 的源码仓库和字节校验已记录，但精确构建修订需由上游构建产物补齐。
