# 用户、访客与状态分享

身份只在显式 `POST /api/identity` 时选择或创建。请求可以是 `{name}`、`{id}`、`{guest:true}`；GET 健康检查、媒体和标注不会创建用户。命名用户存储在 `users.sqlite`，不再依赖工作区数据库。cookie 记录选择，actor 是可信内网的归属声明，不是访问权限。

标注写入需要明确选择身份、匹配的 Origin、`X-VoidPlayer-Action: annotation` 和 JSON。捕获的 `X-VoidPlayer-Actor` 与服务当前 cookie 不一致时拒绝写入。访客使用 guest-UUID cookie；清除 cookie 后无法自动找回。

页面观看状态由 URI 表达。分享按钮把当前片源、时间、色彩/解码条件、视口和布局编码为带 ABI 的自包含链接，不创建工作区文档、不写短链映射、不上传视频。接收者可编辑明文参数或重新分享自己的观看现场；每条链接携带独立状态。旧工作区格式与旧工作区链接不兼容恢复。

标注直接属于片源版本，任何布局打开同一片源版本都同步同一批标注，分享不触发标注发布或移动。服务端按逐条 revision 检查写入，operationId 保证丢失回执可幂等重试；已删除标注只能显式恢复，不能修改源版本或帧锚点。预览与正文独立持久化。详细协议、参数和验证见 [URI 状态与 ABI 分享](uri-state.md)。
