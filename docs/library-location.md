# 媒体库位置输入

媒体库位置框失焦时显示目录名；点击后显示可复制、可编辑的服务内路径。把路径粘贴到同一媒体服务的 VoidPlayer 位置框并按 Enter，即可前往该目录。

语法：`library:/`、`library:*`，或 `library:<root-id>[/<目录>/<子目录>…]`。`root-id` 使用服务端的稳定标识；目录按 `/` 分段，不能含空段、`.` 或 `..`。

| 输入 | 位置 |
| --- | --- |
| `library:/` | 所有媒体库的根目录 |
| `library:*` | 全部媒体，递归浏览 |
| `library:video` | ID 为 `video` 的媒体库 |
| `library:video/test/镜头 A` | 该媒体库内的目录 |

`library:` 后使用媒体库稳定 ID，目录部分保留原有名称。这个表达式相对于当前媒体服务，不能直接粘贴到浏览器地址栏。

HTTP 深层链接直接使用 `/?library=<root-id>&dir=<目录>`；库集合首页为 `/?library=`，全部媒体范围为 `/?library=*`。显式文件链接继续附加 `media=<文件ID>&v=<版本>`，所选库与文件版本互不替代。

旧的 `/?library=1&root=...&dir=...`、`/?library=1` 和 `/?library=1&all=1` 保持兼容，也可粘贴进位置框。历史开关值 `1` 的同名配置库仍使用 `library=1&root=1`，避免被误读为库集合首页。
