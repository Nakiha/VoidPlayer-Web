# v0.6.0 — 共享码流分析与稳定性修复

相对 v0.5.0：

- 码流分析与播放共用 FFmpeg 包索引，支持 WebM、Matroska、TS、PS 和 AVI；复用本地及服务端缓存，保留 PTS、DTS、包大小、关键帧标记与原始包序号，避免分析查询重复读媒体或解码。缺失时间戳及不支持的路径会明确提示。
- 改善分析面板缩放时的采样柱宽度，稳定播放与异步查询期间的帧号显示；分析任务可取消，分析或本地持久化失败不会阻断核心播放功能。
- 加强工作区恢复失败后的回滚与同步状态清理，评审导出保留当前色彩条件；统一 Agent 工具输入校验与解码 Worker 的请求、响应契约。
- 调整按钮反馈、媒体库导航与轨道状态提示，统一最近打开列表的滚动条，改善玻璃面板间的滚动条位置，并使列表、设置与分析面板的滚动边界保持在各自区域内。
- 补充有界错误恢复、启动失败提示和浏览器回归验证，修复工作区链接测试遗漏的加载状态接线、独立包验证的旧导出入口，以及窄屏长文本按钮裁切。

提供 Linux x64、Windows x64、macOS ARM64 独立包及各自 SHA-256 校验文件；每个包内含对应源码 `source.tar.gz`、构建来源与逐文件校验清单。升级前请备份完整数据目录。

已知限制：HTTPS 播放速度基准为非阻断报告，部分双轨 HTTPS 与 headless Chromium 混合 HEVC 场景仍未达到既有实时阈值；Linux 无 GPU runner 的 1080p FLV/HEVC WASM + SwiftShader 预检为约 0.37×，速度与呈现间隔明确保留为未达标的性能报告，功能检查仍阻断发布。功能门禁通过不代表所有环境均能实时播放。macOS 包暂未签名和公证。详见[FLV 负面记录](https://github.com/Nakiha/VoidPlayer-Web/blob/v0.6.0/docs/evidence/release-0.6.0/flv-legacy-hevc-ci.json)、[性能核验记录](https://github.com/Nakiha/VoidPlayer-Web/blob/v0.6.0/docs/i18n-performance-review.md)与[便携运行说明](https://github.com/Nakiha/VoidPlayer-Web/blob/v0.6.0/deploy/standalone.md)。
