# v0.5.0 — 中英界面、自定义配色与共享评审

相对 v0.4.0：

- 新增简体中文与英文界面，覆盖播放器、工作区、管理页和证书连接指南；切换语言时保留会话、弹窗和编辑状态。
- 新增自定义基础配色、预设色板与首屏主题恢复；调整设置和标注恢复控件、玻璃标题栏及内容区滚动条，补充聚焦快捷键与轨道完整路径提示。
- 统一可写工作区分享与标注讨论，完善工作区链接、视口手势及播放器交互；通过绑定代次检查，阻止旧工作区请求覆盖切换后的状态。
- 重构共享索引任务与流传输：媒体库 FLV 使用服务端共享扫描器建索引，MP4 在解码策略前选择包索引方案；MPEG-TS 使用仅解封装索引，完整扫描并持久化后再分批传输，首帧仍可提前呈现。
- 修复 FFmpeg 可用覆盖范围与索引等待取消、FLV 不完整索引时的首帧持有及有界损坏恢复、原生 HEVC 异步回调帧序，以及色彩切换失败时的隔离与回滚。
- 统一测试清单、执行入口和生命周期管理，扩充发布所需浏览器回归，并提供受保护的本地可再生成产物清理工具。

提供 Linux x64、Windows x64、macOS ARM64 独立包及各自 SHA-256 校验文件；每个包内含对应源码 `source.tar.gz`、构建来源与逐文件校验清单。升级前请备份完整数据目录。

已知限制：HTTPS 播放速度基准为非阻断报告，部分双轨 HTTPS 与 headless Chromium 混合 HEVC 场景仍未达到既有实时阈值；功能门禁通过不代表所有环境均能实时播放或已证明性能等价。macOS 包暂未签名和公证。详见[性能核验记录](https://github.com/Nakiha/VoidPlayer-Web/blob/v0.5.0/docs/i18n-performance-review.md)与[便携运行说明](https://github.com/Nakiha/VoidPlayer-Web/blob/v0.5.0/deploy/standalone.md)。
