# VoidPlayer 0.2.3

本版新增浏览器色彩混合上屏提醒，并补一条 Windows 诊断脚本；不改变解码路径选择、色彩转换数学与服务端技术路线。

- 浏览器色彩混合提醒：`colorMode === 'browser'` 且已上屏轨道中同时存在原生帧（WebCodecs）与软件帧（FFmpeg WASM）时，弹常驻 toast（需手动关闭），提示色彩可能不准并提供“前往色彩设置”按钮，直达“色彩与解码”页。条件解除（切换模式/只剩单一路）后自动清理。只读会话状态，不改解码与色彩管线，Agent 行为不变。
- 新增 `npm run test:color:browser-match`（Windows Chrome/Edge）：浏览器色彩下原生上屏帧与真实 WASM 软解上屏帧的同 PTS 对比，WASM 原始字节先对 FFmpeg CLI 参考逐字节核对，另附固定候选（baseline/matrix601/GAMMA22 组合，无拟合参数）的诊断扫参。仅输出本地报告，不进默认管线，不影响 Mac。

升级沿用 v0.2.2 数据目录与数据库 schema；缩略图 recipe 未变，已有封面继续有效。正式下载以三平台校验完成后的公开 Release 为准，下载归档和同名 SHA-256 文件后核验；包内 release.json 记录精确应用修订、Bun 与解码器来源以及资源摘要。
