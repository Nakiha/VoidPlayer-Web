# v2.3.0 — 逐帧编码检查与独立分析核心

相对 v2.2.1：

- 码流分析使用与播放分离的固定版本 WASM core，支持本地文件和媒体库的多线程分析。可按片源选择播放、分析线程；分析按编码调整执行策略并逐帧交付已验证结果。
- AVC、HEVC、VVC 编码特性进入轨道检查器并支持导出。分析浮层增加块划分、尺寸填色、预测类型、QP 热图，以及 HEVC CU 深度／VVC QT 深度；可调整边界、文字和透明度，按面积或块数查看当前帧分布、突出选中类别并导出当前帧及可选块明细。
- 新增指定画面的预测明细产品，供本地 Worker、媒体库 HTTP 和页面工具按需读取：AVC／HEVC／VVC 帧内模式、HEVC 实际 PU 与 L0／L1 参考及四分之一像素运动向量、VVC 帧间工具和运动模型。VVC 逐块运动向量、DMVR 和 BDOF 尚未导出；图表和像素通道不会自动开启重型采集。
- 重整用户设置、标注同步冲突与评审活动界面，统一缓存控制与分享快照行为，减少重复媒体库请求，并完善解码资源加载诊断和应用图标。
- GitHub Release 新增与 ChatGPT Sites 相同构建目标的静态网页包 `voidplayer-2.3.0-sites.tar.gz`，附 SHA-256 校验文件、构建身份和文件哈希。它包含本地播放、标注及分析所需资源，不需要 Node 服务；解压后以 HTTPS 或 localhost 静态托管 `dist/`。包内不绑定已有 Site，也不包含媒体或本机数据。

## 升级说明

完整替换对应平台的程序和前端资源。播放与分析分别锁定已发布的上游源码，分析产品升级为新配方以区分块深度和预测能力；旧缓存不能作为新能力的证明。原有 ABI 1 URI 观看状态、v2.2.x 分享链接和按片源版本保存的标注继续兼容。

提供 Linux x64、Windows x64、macOS ARM64 程序包和独立静态网页包，各附 SHA-256。静态版只处理浏览器本地文件，不装配媒体 API、服务器身份、分享或远端标注同步；无跨源隔离时沿用单线程路径。显示仍要求可用的 WebGPU，能力取决于浏览器、GPU 和片源。
