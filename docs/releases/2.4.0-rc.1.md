# v2.4.0-rc.1 — 画面增强与外部媒体库

- 完整版和 Dock PWA 支持对 SDR RGB 视频逐轨应用 WebSR 增强。提供 2×、串联 4× 和可调锐化，输出尺寸在就绪后显示。倍率和锐化设置随工作区恢复，增强开关默认关闭。安装包附带权重来源、SHA-256 和 MIT 许可。
- 媒体库可以接入外部只读片源。管理页支持浏览和同步提供方目录，播放器可按片源版本打开视频。仓库附有参考提供方和接口示例。
- 修复部分视频启用音频时的断续噪声。专注模式在指针于视口内移动时显示操作入口，所有面板收起时自动收起顶部工具栏。

这是 2.4.0 的首个候选版本。完整升级请同时替换程序与前端。Linux x64、Windows x64、macOS ARM64 和 Sites 静态包均提供 SHA-256 校验文件。Sites 包支持本地播放，画面增强由完整版和 Dock PWA 提供。
