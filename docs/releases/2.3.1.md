# v2.3.1 — 浏览媒体库时按需生成封面

- 打开目录、滚动列表或查看最近打开的媒体时，服务端按需生成并缓存首帧 JPEG。多人查看同一视频共用一次解码，目录可以先显示。独立程序随包提供解码器。
- 播放器媒体库支持列表与分栏浏览，媒体库管理入口移到库列表上方。播放器和管理页的路径栏支持按段拷贝绝对路径、库名、文件夹名或文件名。
- 本地文件卡片可拷贝文件名；宿主提供真实路径时还可拷贝绝对路径。普通浏览器隐藏本机路径，菜单会提示该限制。

完整升级请同时替换程序与前端。已缓存的媒体库封面继续复用。本地文件仍在浏览器生成预览。Linux x64、Windows x64、macOS ARM64 与 Sites 静态包均附 SHA-256 校验文件。
