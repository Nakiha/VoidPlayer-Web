# v2.4.0 — 裸码流、码流分析和 PWA

- 播放器和媒体库支持 H.264、H.265、H.266 Annex-B 裸码流。大文件可以先显示首帧，再后台扫描索引。分析面板可按显示顺序和推导的解码顺序查看帧，并显示 GPB 参考关系。
- 分析遮罩增加编码大小，按 CABAC 位流位置估算各块码量。多轨悬浮面板显示对应位置的块、QP、预测类型及实际使用的 Merge、MMVD、CIIP、GPM。导出当前帧时附带块和帧间预测明细。
- 完整版和 Sites 静态版均支持 PWA 安装、离线打开和 Chromium 桌面文件关联。系统打开视频时，文件检查和首帧解码可与播放器初始化并行。支持窗口控件叠加的浏览器可在标题栏区域显示工具栏。
- 完整版保留 WebSR 逐轨增强和外部只读媒体库。WebSR 提供 2×、串联 4× 和可调锐化。修复部分视频播放时的断续音频，以及点击时间轴后方向键无法逐帧的问题。

Linux x64、Windows x64、macOS ARM64 程序包和 Sites 静态包均附 SHA-256 校验文件。完整升级请同时替换程序与前端。
