# VoidPlayer 0.2.1

本版收敛片源生命周期与缩略图资源管理，不改变浏览器解码、服务端提供文件和派生缓存的技术路线。

- 普通载入、工作区恢复和色彩/解码设置重开共用可取消的候选片源入口。恢复后的片源可再次切换设置；取消慢速打开立即释放会话队列，迟到的解码源独立释放。
- 软件帧缩略图在独立、受限 Worker 中转换和编码，只生成小尺寸 RGBA，避免为封面展开全尺寸中间图。原生 sample 继续直接绘制到小画布。
- 完整帧占用绑定独立任务凭证，旧任务完成不能释放新任务的占用。500ms 到期主动释放并终止像素 Worker；慢编码、存储和上传不再串行阻塞后续完整帧。事件循环定时器不提供实时系统保证。
- 本地缩略图以小 JPEG 字节持久化，兼容旧 Blob 记录，修复 WebKit 临时浏览器上下文的 Blob 存储失败。
- PR 和发布验证自动发现全部单元测试，接入缩略图、启动、恢复后切换设置的浏览器回归；用真实解码调用与网络请求验证辅助工作不重读视频，移除未接入操作的恒零计数。
- 更新八轨架构、服务器工作区保存与下载说明，在管理入口和部署文档明确用户名是归属而非认证。

大 FLV 索引处理仍在服务端请求线程执行。本版增加独立客户端/服务器进程压测脚本，实测风险与后续隔离范围见 [可靠性核对记录](../reliability-0.2.1.md)。不将此项或非阻塞 CI 性能报告表述为已解决的性能保证。

升级沿用 v0.2.0 数据目录与数据库 schema；缩略图 recipe 更新，旧封面可由新首次载入逐步替代。正式下载以三平台校验完成后的公开 Release 为准。
