# v1.0.0-alpha.2 — 码流分析 Alpha Preview

这是 1.0.0 的 alpha 预览版，供试用和反馈；稳定版 Latest 仍为 v0.7.0。

相对 v0.7.0：

- 普通 MP4 的 AVC/H.264、HEVC/H.265、VVC/H.266 支持本地文件与媒体库码流分析。本地分析在浏览器独立 Worker 运行，媒体库分析由服务端独立 Worker 执行；分析核心与播放核心分离，按需加载。
- 提供块边界、QP 热图和基础 intra/inter 模式遮罩，以及 NAL 类型/大小和活动候选参考列表图。参考列表表示解码器当前可用的 L0/L1 候选关系，不代表每个块实际使用的参考帧或运动矢量。
- NAL/参考图可触发逐 GOP 持续分析，支持进度、取消、有界缓存和并发设置；图表共用 PTS/DTS 时间轴、缩放和多轨悬浮详情，展示容器头部配置 NAL，改善轨道控制和遮罩工具条交互。
- 多轨码流图缩放时按同轮查询结果一致更新，避免新旧桶网格混用导致柱宽短暂回落；浏览器验收继续检查原有平滑缩放阈值和完整整片分析终态。

提供 Linux x64、Windows x64、macOS ARM64 独立包及同名 SHA-256 校验文件。停止旧程序并备份完整数据目录，再完整替换程序及资源，使前端、服务端、播放及分析核心一起升级。保留旧包和停机备份以便回退。

## 已知限制

- 本版只交付 issue #56 的部分能力，不是完整验收；复杂编码工具、块级实际引用和 MV 可视化尚未交付。
- 仍缺少完整独立语义 oracle、真实几何组合验收和服务端全局资源压力验收；跨区间稀疏缓存补洞仍有限制。缓存淘汰、取消和服务重启不保证保留或自动恢复完整分析覆盖。
- 历史 ABBA 16 样本性能对照中，基线和功能分支均未通过实时阈值；不宣称无性能回归或全部实时验收。CI 功能门禁通过不代表所有设备、素材和多轨场景均能实时播放。
- 既有 HDR、顺带音频及平台能力边界继续适用；macOS 包暂未签名和公证。
