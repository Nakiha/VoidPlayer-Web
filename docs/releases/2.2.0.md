# v2.2.0 — URI 观看状态、独立标注与触摸操作

相对 v2.1.0：

- 取消服务器工作区文档、本机工作区检查点和旧工作区文件导入。片源、播放位置、对齐、视口、工具区及媒体库导航/搜索由 URI 表达；可编辑参数直接跳转状态，浏览器前进/后退复用同一恢复流程，并隔离迟到请求。
- 分享改为带 ABI 的自包含压缩链接。ABI 1 通过固定字段字典、编号、默认值省略及资产/版本二进制表示减少长度，再比较原文、Deflate 和 Brotli 结果。后端解码返回观看状态，不保存短链到工作区文档的映射；链接不包含视频、标注正文或预览。
- 标注按片源 ID、内容版本及服务命名空间独立保存和同步，不再依附工作区或分享链接。保留事务写入、幂等操作、删除墓碑、冲突处理和独立预览上传；后台更新不打开媒体、不 seek、不抢焦点。
- 视口支持单指平移、双指平移与缩放；打开标注工具后，单指绘制、双指调整视图。第二指加入撤销未完成笔画，抬指不会误画；修复缩放边界上的双指平移偏差。
- 分析栏新增保持时间跨度的当前帧定位和持续跟随，PTS/DTS 使用实际帧时间；手动浏览停止跟随。点击负载率曲线可跳到悬浮面板里的参考帧，多轨按邻近曲线选择，DTS 图仍按该帧 PTS 定位。
- 媒体库地址栏输入 `library:库ID/文件路径` 可跳到文件所在目录并自动上屏，目录路径仍只导航，迟到查询不会覆盖后续输入。媒体库默认使用紧凑列表，列表密度与布局按钮采用中性色和状态切换动画；“自有色彩”更名为“默认色彩”。完善跟随按钮、轨道控件间距及应用图标。
- 修复 URI/Agent 打开时缩略图只留在本机而漏上传的问题，冷 URI 的首帧提交也参与生成。后端按片源版本共用 JPEG 缓存，目录分页和最近打开列表自动发现其他用户的新图，读取列表不触发视频解码。
- 完善显式媒体 API、文件操作的资产身份保留、日志分页、管理页及相关浏览器回归。
- 本机页面桥按实际片源与身份绑定授权，播放时间、视口和布局的自动 URI 更新不再误断开连接；更换片源或身份仍须重新授权。

## 升级说明

**本版本不兼容旧工作区文件、工作区接口及旧分享链接，也不迁移其内容。** 升级后使用 URI 与新的 ABI 分享链接；旧工作区中的标注不会自动转为新的片源版本标注。已有数据文件不会被自动删除。

升级前停止旧服务并备份整个 `data/`，完整替换对应平台的程序和资源。保留旧包及停机备份以便回退，不同时运行两个指向同一数据目录的实例。提供 Linux x64、Windows x64、macOS ARM64 独立包及 SHA-256 校验文件；macOS 包暂未签名和公证。

本地文件不会嵌入链接，不能通过压缩分享转交给其他设备；接收方仍需具备片源访问能力。缩略图只复用已解出的首帧，不为封面额外回到开头解码。Sites 静态版继续只处理本地文件，不装配服务器分享、远端标注同步或媒体 API。

视频显示仍要求可用的 WebGPU 和 HTTPS/localhost。HDR、码流分析及硬件解码能力取决于片源、浏览器、GPU 和显示环境。
