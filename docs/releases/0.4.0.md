# v0.4.0 — 服务端索引与稳定定位

- 版本化媒体库片源由服务端后台构建 FFmpeg 索引，并按身份缓存到 SQLite；每个 batch 先持久化再通过 NDJSON 流传给浏览器。
- MPEG-TS 服务端建索引改为 demux-only，不为索引逐包解码；扫描到 EOF 后才持久化并分 batch 传输完整记录。首帧仍独立先呈现，索引保持 `building` 代表完整记录尚未全部导入，不代表 demux 仍在运行。
- FFmpeg 回退路径在索引完成前先返回首个可呈现帧。扫描失败不会把未完成记录标成完整覆盖；未覆盖的 seek 继续等待索引或返回明确错误。
- 流式续传由 build ID 和单调 batch 序号约束；服务端重启并产生新 build 时拒绝混接旧索引前缀。SQLite schema 与缓存校验同步升级。
- 保持 FLV 和 MP4 包索引的专用记录格式与适配路径。FLV 冷索引仍在客户端渐进生成，MP4 包索引路径不迁移到本次 NDJSON 协议。
- 修复拖动时间轴 seek 时分享/片源操作图标闪烁，并统一片源添加与移除图标的线宽和 hover 背景。
