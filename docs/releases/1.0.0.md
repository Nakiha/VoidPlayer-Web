# v1.0.0 — 按需码流分析与评审体验

相对 v0.7.0：

- 新增独立于播放链路的码流分析：本地文件在浏览器 Worker 中处理，媒体库任务在服务端 Worker 中处理；分析核心按需加载。普通面板默认只读码率、帧大小和索引，启用 QP、NAL 或参考图后才请求深层分析。
- 提供编码块边界、8-bit 亮度 QP 热图、基础 intra/inter/skip 模式，以及 NAL 大小/类型和参考候选关系图。图表共享 PTS/DTS 时间轴、缩放、平移和多轨悬浮详情；按可见区间请求完整 GOP，支持暂停、继续、取消、有界缓存和服务端并行数设置。
- 分离轻量逐帧摘要与精确块产品，复用已验证的源、配置和 picture 身份；持久缓存支持服务重启后的复用，损坏、淘汰或来源变化时重新验证和补算。已覆盖区间的导航不再短暂进入分析队列；工作区恢复可较早还原面板与保存的区间，并保留标注卡片预览。
- 扩展经过矩阵验证的有限文件输入，包括普通 MP4、有限自包含 fMP4、legacy/Enhanced FLV，以及限定组合的 TS、Matroska/WebM。容器解析和包索引更多由共享 JS 层承担；WebCodecs 与 packet WASM 消费相同压缩包。支持取决于编码、封装、配置和随机访问条件，不能按扩展名推断全部组合可用。
- 更新固定的播放与分析 WASM 核心，包含经验证的 SIMD 路径及受准入条件约束的 HEVC/VVC 分析优化。Worker 通信、取消、资源释放、缓存身份和播放连续性增加明确的失败处理与回归覆盖。
- 改善媒体库恢复、定位和右键操作、分享工作区、顶部设置可达性、分析区间编辑和加载状态。统一玻璃控件反馈与连续点击区域，调整浮层避让、时间线预览和窄屏分析卡片。
- 分析遮罩的不透明度统一作用于最终图层：0% 隐藏、100% 使用不透明填色。新增可选块内文字，显示 QP 或本地化预测模式；小块及视口外文字跳过，切换复用当前分析缓存，不触发 seek 或新分析。
- 测试改用统一清单和领域场景，分别报告 Node、浏览器、真实媒体及原生包验证；失败保留阶段、截图和请求证据。发布汇总要求全部必需检查通过，并核对三平台版本、修订及共享 WASM 字节。

## 下载与升级

提供 Linux x64、Windows x64、macOS ARM64 独立包，每包附同名 `.sha256` 校验文件；最终用户无需安装 Node、Bun 或 FFmpeg。

停止旧程序并备份完整数据目录，再完整替换程序及资源，使前端、服务端、播放和分析核心一起升级。先核验下载文件的 SHA-256；保留旧包与停机备份以便回退。macOS 包暂未签名和公证。

## 支持与验证边界

- 精确遮罩要求可验证的 AU、源帧身份和完整块几何。field/layer、复杂或变化的配置、未准入随机访问与损坏输入不保证支持；具体组合以[可执行矩阵](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/scripts/bitstream-analysis-matrix.json)及[JS 容器说明](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/docs/js-container-migration.md)为准。VP8/VP9 的包统计不代表支持块或 QP 分析。
- 高位深亮度 QP、chroma QP、块级实际参考帧和运动矢量可视化仍未交付。参考图显示候选关系，不代表每个块实际采用的参考。未知或不支持的数据保持明确状态，不补成 0。
- 缓存受预算、版本和源身份约束；重启不恢复解码器内存或旧传输游标。暖命中仍可能读取验证元数据或重建参考，不能理解为零 I/O 或永久保留全部覆盖。
- 本版不宣称所有历史性能问题已经解决。既有 headless/reference、多轨和部分素材的实时阈值失败记录继续保留；固定 VVC 样片上的 core 改善不能推广为所有 App、分辨率、编码工具或平台的加速。详见[实际测量边界](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/docs/validation/pr109/README.md)和[容器迁移性能记录](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/docs/evidence/demux-removal/final/README.md)。
- v0.7.0 的 HDR 与顺带音频限制继续适用：HDR 取决于浏览器、GPU 和显示设备能力，自动化通过不代表实体屏幕已校准；音频只观察已有视频缓存，可能中断，不承诺连续音频或采样级同步。

详见[码流分析](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/docs/bitstream-analysis.md)、[HDR 支持](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/docs/hdr-support.md)、[顺带音频](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/docs/opportunistic-audio.md)、[验证说明](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/docs/testing.md)和[便携运行说明](https://github.com/Nakiha/VoidPlayer-Web/blob/v1.0.0/deploy/standalone.md)。
