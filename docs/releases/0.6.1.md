# v0.6.1 — 损坏容器的安全恢复

相对 v0.6.0：

- 修复 FLV 尾部垃圾或重同步失败导致整条轨道无法播放的问题。使用有界扫描验证连续 tag，并在安全的随机访问点恢复；无法继续时保留已验证的有效前段。
- MPEG-TS、PS、Matroska/WebM 和 AVI 在解封装明确报告损坏时可保留完整 GOP 的前段。MP4 验证尾部异常数据与 sample 范围，截断时舍弃可能缺少参考帧的末尾 GOP。
- 播放时长、seek、服务端索引和缓存重开共享同一恢复边界，并显示损坏警告。修复冷启动索引流未发送最终损坏边界的问题，避免首次打开与缓存重开的行为不同。
- 修复裁剪版 WASM 对 MPEG-PS 视频的编码探测，并加强单线程、多线程、保留帧像素、反向与尾帧 seek、缓存导入及短读 IO 错误回归。独立包验收使用共享 FLV 索引版本。

提供 Linux x64、Windows x64、macOS ARM64 独立包及 SHA-256 校验文件。请完整替换程序及资源，使前端、服务端和两种 WASM 核心一起升级；升级前备份数据目录。

恢复仅保留可以安全确认的内容，不能补回缺失帧。没有完整 GOP、未被解封装器识别的编码损坏、IO/资源版本错误或不支持的配置仍可能导致失败。性能限制沿用 v0.6.0：功能验收通过不代表所有环境均能实时播放；macOS 包暂未签名和公证。原 sd5 片源未在构建环境中，回归使用同类合成损坏样片。详见 [容器恢复策略](https://github.com/Nakiha/VoidPlayer-Web/blob/v0.6.1/docs/container-recovery.md)和[便携运行说明](https://github.com/Nakiha/VoidPlayer-Web/blob/v0.6.1/deploy/standalone.md)。
