# VoidPlayer 0.2.2

本版新增 YUV 通道隔离诊断视图，收敛片源列表展示与缩略图刷新行为，不改变浏览器解码、服务端提供文件和派生缓存的技术路线。

- YUV 通道隔离查看：像素尺寸栏右侧新增通道下拉（RGB/Y/U/V）。`Viewport.channel` 随快照、工作区与 Agent `setViewport` 共用；WebGPU / WebGL / CPU 三条 YUV 后端共用同一灰度数学，仅 `yuv` 帧生效（Y 取归一化亮度灰阶，U/V 取归一化色度 +0.5 中灰，不经矩阵/基色变换）。非 YUV 资源（浏览器托管帧、RGBA 回退）保持 RGB，不伪造通道。暂停切换重解当前帧，播放中后续帧自动生效；缩略图封面恒为 RGB。色彩链路契约见 `docs/color-pipeline.md`。
- 移除片源状态行：扫描进度与读取错误只在管理后台展示，前端媒体库/片源列表不再保留状态行，避免长文本把列表顶下去。
- 修复最近访问/媒体库缩略图闪烁：缩略图写入单写、原位补、稳定复用。服务端与本地不再双写同一 `<img>`；旧 object URL 延迟 10s 释放，避免新图未解码时旧图先断；服务端就绪经通知原位补图，不等待无关的全列表重建；真正无图保持 0 占位，不加空框或破图图标。
- 修复片源工具栏重复间距。

升级沿用 v0.2.1 数据目录与数据库 schema；缩略图 recipe 未变，已有封面继续有效。正式下载以三平台校验完成后的公开 Release 为准，下载归档和同名 SHA-256 文件后核验；包内 release.json 记录精确应用修订、Bun 与解码器来源以及资源摘要。
