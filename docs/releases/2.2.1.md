# v2.2.1 — 更短的分享链接与评审界面改进

相对 v2.2.0：

- 分享新增二进制封装，直接保存资产与内容版本字节，以位域、变长整数、固定字段顺序、默认值省略和重复字符串引用减少冗余，再比较未压缩、Deflate 与 Brotli 的实际链接长度。带布局的 1／2／8 轨样例 token 从 267／308／560 字符降至 76／114／338 字符；实际长度取决于观看状态。继续读取 v2.2.0 的 ABI 1 分享链接。
- 分享期间保留按钮外观和焦点，重复点击复用同一次编码与复制，避免禁用再恢复造成闪烁。已上屏轨道包含本地文件时禁用分享，并通过 tooltip 说明原因；未上屏的本地文件不影响分享。
- 首次打开空白首页保持干净地址，不再自动展开整份默认布局与比较条件。载入片源后继续同步观看 URI；明文参数中的 JSON 与中文仍使用正常 URL 转义。
- 分享记录平移时主画面的适配尺寸，恢复时按接收端实际画面尺寸缩放偏移，修复不同窗口和面板布局下的 pan 偏移；旧链接不再误用接收端上一个场景的尺寸。右键平移使用固定交互层，保持慢速移动及停顿期间的抓取手型。
- 媒体库紧凑列表开关联动本地文件列表；路径控件与本地列表之间新增可拖动、可键盘调整的分隔条，其高度进入布局状态。本地文件支持右键、长按和键盘菜单，提供上屏／下屏、拷贝文件名与移除文件；移除会关闭对应轨道并移出最近记录，不删除磁盘原文件或已有标注。
- 标注卡片将作者与删除按钮移到时间、帧号所在的顶部信息区，描述位于预览图上方。窄卡片允许作者换到第二行，垃圾桶保持第一行。
- 收紧子轨道时间轴末端留白与时长条内边距，使最长轨道的时长文字与顶部标尺末端文字对齐；保持刻度、拖动定位和 EOF 边界一致，并适配高对比边框。

## 升级说明

完整替换对应平台的程序与前端资源。新二进制分享封装需要 v2.2.1 服务端解码；状态 API 的 `abi:1`、已有 URI 观看状态及 v2.2.0 分享链接继续兼容。分享不包含视频、标注正文或预览，本地文件不会通过链接转交给其他设备。

Sites 静态版继续只处理本地文件，不调用媒体 API 或装配服务器分享。播放与分析 core 的锁定修订保持不变。
