# 分析 WASM 评分架构与支持范围

实例并发、算法配额、聚合预留及配置变更见 [评分资源管理](quality-resources.md)。

本页是当前评分执行架构与输入域的统一说明。领域文档保留各自数值、
HTTP、结果与证据语义；历史修复、失败和实测在 [收敛记录](quality-convergence.md)。
`native-*` 路径、`Native*` 类名和旧 schema 字段为兼容历史而保留，不是安装原生
组件或限制 Linux 部署的要求。维护者原生 CLI 对照与生产执行分开。

## 执行边界

VMAF/CAMBI 通过既有分析产物的 `vpa_quality_*` ABI 1 接收像素；
XPSNR 使用同一产物的 `vpa_xpsnr_*` ABI 1。
没有第三个产品 core，没有 avfilter、评分 CLI 或临时原始 YUV 文件。
播放产物在独立后台 Worker 中解码，不访问页面播放实例。PSNR/SSIM 保留
共享像素实现；两端选择、色彩、ROI 和源证据相同。

分析组件由 `QualityApplication` 拥有的 `AnalysisComponentOwner` 统一核验。启动核验使用有界异步文件读取及 crypto 线程池 SHA-256；能力查询先异步检查 dev/ino/size/mtimeNs/ctimeNs，只有身份变化才重新哈希，未变化时读取先前验证的同一文件快照；三个评分器共用正在进行的核验，不在 HTTP 主线程同步读取/哈希完整 WASM，也不在 SQLite 提交事务内做文件 IO。文件预算为 manifest/provenance 各 256 KiB、glue 4 MiB、WASM 64 MiB；核验占用 inspection 准入（256 MiB 内存预留、69 MiB 读取、1 线程）。忙时能力接口明确报告延后核验，可保留先前已验证描述，不冒充本次核验完成。

提交事务只检查已验证的组件快照；任务进入实际执行后，在同一执行准入内再次验证当前文件，冻结实际组件契约，并在执行及最终来源核验后再次检查。产物变化会失效快照，拒绝发布分数；没有永久缓存或跳过执行期核验。关闭时先排空评分执行，再释放组件 owner。

libvmaf 固定为 v3.0.0（`17a67b238ce0539bdeafdc95961abac64fa16ea8`），
模型 v0.6.1 / NEG、单线程、关闭 CPU 专用指令、CAMBI window 63。
CAMBI 修改仅将官方 gray16le 热图写入内存；五尺度转换与算法保持不变。
构建、许可证、模型 hash、算法修订和 ABI 均由上游产物清单携带。
Web 的 release lock 只指向已提交并推送的上游修订。

新结果带 `executor: analysis-wasm`、分析 glue/WASM/manifest/provenance
hash 和实际线性内存/耗时。旧 native 结果保留原二进制和 supervisor 身份，
不改写为 WASM。CPU/RSS/退出信号不能捏造成 WASM 观测值。

## 时钟与帧身份

MP4 原始 ticks/timebase 保留在 sample 和附件中。对应关系按有理数精确
比较；微秒投影不建立身份，不做 nearest、补帧或 PTS 改写。输入 AU token
通过 decoder opaque identity 传到输出，每个输出核对 token、epoch、原始
PTS/DTS 投影、包字节数/hash 和错误标志。B 帧按实际呈现次序送入评分器。

每侧同时只保留一个解码上下文和一个复制的输出帧。每个闭合 GOP 解码一次，
消费者拉取下一对才继续解码；完整排空后才能提交结果。GOP 身份表最多512槽，
单窗口压缩字节、帧尺寸和堆预算继续生效。没有把整个片段原始像素存入内存。

单独帧测量仍返回完整窗口成本。连续测量的每帧 `work.accounting` 为
`incremental-shared-gop-v1`：首次进入窗口计入成本，其余帧共享窗口，不能
把逐帧窗口成本相加冒充实际解码量。窗口输出见证仍包含完整 GOP。

## ROI 与片段

VMAF/XPSNR 支持同一片段中固定的偶数 ROI，最小64×64。两侧以同一个源坐标 ROI
裁剪 Y/U/V，保持位深、样本值、chroma 对齐，无缩放或色彩转换。一个片段
共用一次相应评分上下文及最终 flush；ROI 评分是独立重算，不是整帧分数的
空间分解。配套 PSNR/SSIM 使用同一 ROI。ROI、尺寸、裁剪后原始字节 hash
和时域边界均进入证据，UI 需明确区分整帧与裁剪区域。

当前 VMAF/XPSNR 声明上限1024帧、4096×2304，CAMBI 上限1024帧、1920×1080；实际准入还受调用者预算、结果字节、
源读取和截止时间约束，不保证所有上限组合可同时满足。`maxRawBytes` 在
WASM 路径是累计输入像素量，不是磁盘预留；`nativeMemoryBytes` 兼容字段
限制分析线性内存；`nativeCpuSeconds` 兼容字段作为更保守的墙钟截止时间，
与 `maxElapsedMs` 取较小值，不声称采集了 WASM CPU 时间。

长序列附件保存完整被选帧/GOP证据及首帧、选中帧、末帧的时钟见证，并保存
完整序列表的 SHA-256 和结果摘要。完整映射仍在原任务分页中。该紧凑附件
明确是摘要绑定，不声称包含全片逐帧映射。历史短序列附件保留原结构。

## 容量与回执

运行中的评分任务预留最坏结果量，停止后按实际 UTF-8 输入、冻结计划、任务正文、重执行/发布回执、结果和热图
计费，另有每条1024字节的标量余量。SQLite页与WAL开销不属于逻辑载荷预算。
任务数量不再是 VMAF/CAMBI/XPSNR 的终身准入上限。任务中心在数据库筛选
后建立有界冻结快照，不能先取各类首页再伪装完整筛选；超出快照预算明确
要求缩小筛选，旧任务可直接访问。

任务中心可显式释放已物理停止的私有评分结果。原任务、输入、提交回执和
幂等 key 保留，原提交回放不会重算。冻结过发布的结果，以及当前或历史
共享评审记录引用的结果不能释放。其他任务存储的容量策略统一见阶段四；字节上限仍生效，不能宣称历史可无限保存。

CAMBI 连续区间同样逐 GOP 解码、按消费端确认继续送帧。运行中已持久保存的
分数和热图可由 owner 有界分页预览，明确为 provisional，不能发布或作为已核验
源快照；只有完整排空、再次核验源与索引后才能发布。
显式 stop-and-keep 在当前闭合 GOP 排空后停止，核验并保留 partial 结果；
selected/scored/unscored 保留原范围，官方池化仅覆盖已评分前缀，不将缺口计零。
立即 cancel 仍丢弃暂存结果。取消须同时
等到 Worker 退出和父进程写入回调结束才释放计算名额。最终读取核验也
计入实际索引工作量。CAMBI 的兼容字段 `maxTemporaryBytes` 限制实际五尺度
热图加有界结果的存储预留；不再按已删除的原始 YUV 文件或六份 FSIZE 上限
计量。累计像素输入仍独立受 `maxRawBytes` 限制，历史输出预算记录不改写。
长区间重执行契约用完整选择表摘要与首末帧固定输入，
不在小尺寸确认请求中重复整个选择表；旧短区间契约仍可读取。

## 第一阶段验收

- 35 项真实分析 core 测试通过：官方整帧/ROI VMAF、NEG、CAMBI 对照；
  VMAF 绝对容差1e-5，CAMBI1e-6，热图逐帧逐尺度 SHA-256 完全相同。
- 4096帧同一评分上下文重复三轮，线性内存无逐片增长；这项只证明内核。
- 实际 HTTP 验收：五种常见帧率、8/10-bit CAMBI、8/10-bit ROI、20次连续
  提交及结果释放/回执重放/共享保留。
- 三组192帧、64帧GOP、B帧的 H.2648 / HEVC8 / HEVC10 实际 HTTP 流程
  完成评分和候选。每组只解码384个双侧输出，源像素整体 SHA 和官方每帧/
  池化 VMAF 对照通过。
- 上游 ST/MT 共用身份实现：1216个输出与原生逐字节一致，18类故障注入
  被拒绝，512槽无旧32位位移别名。

后续阶段的容量、生命周期、XPSNR、浏览器和发布包验收，以及尚未关闭的
问题，以 [收敛记录](quality-convergence.md) 为准。第一阶段数据不代表最终全平台验收。

## XPSNR 与旧部署迁移

XPSNR 固定 FFmpeg 算法修订 `8998a1a670c81a04d144c36f9e2d3aa680c10720`，
上游构建仓库将标量算法独立编入分析 core，不链接 AVFilter/framesync。
reference-first、两帧历史、精确帧率、clip reset 与官方池化均保留；结果保存
完整 double 数值和统计 JSON hash，不从四位小数帧分数重建池化。
独立官方 CLI 仅用于维护者生成对照夹具，不是运行依赖。

安装包自带两套已固定产物（播放/分析）。旧配置 nativeVmaf/nativeXpsnr
仅为兼容已有配置文件而接受，运行时忽略；不用安装原生组件。旧 native
结果/附件和中断进程恢复保留，新的任务不再创建该类进程或临时 YUV。
已有执行见证与新 core 不一致时，重执行须重新表达意图，不能改写历史身份。
